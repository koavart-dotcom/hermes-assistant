# Опасные действия агента — только после явного подтверждения Артема

Правило из CLAUDE.md: любое действие, меняющее состояние, выполняется только после явного «ОК».
Этот список — источник истины; он же продублирован в skills (`skills/remote-hosts/SKILL.md`) и в системном
промпте агента. Обновлять при добавлении новых инструментов.

## Всегда требует подтверждения
| Область | Действия |
|---|---|
| Файлы (Mac, ПК, сервер) | удаление, перемещение, перезапись существующих файлов вне временных каталогов |
| Питание | выключение, перезагрузка, сон любой машины |
| ПО и службы | установка/удаление программ, запуск/остановка/изменение служб, launchd/systemd/планировщик |
| Система | реестр Windows, системные настройки, пользователи и права, SSH-ключи и `authorized_keys` |
| Git | `push`, `reset --hard`, удаление веток, правка истории |
| Сеть | правила файрвола, DNS, VPN, отключение интерфейсов |
| Деньги и внешние сервисы | любые покупки, отправка писем и сообщений от имени Артема третьим лицам |
| Хелпдеск (когда подключим) | ответ клиенту, закрытие тикета, смена исполнителя (L1/L2 по `docs/deka-scenarios.md`) |
| Умный дом (на паузе) | замки, отопление, электропитание |

## Запрещено всегда (даже с подтверждением)
- удаление корня диска, профиля пользователя, `~/.hermes`, репозиториев без бэкапа;
- форматирование дисков, отключение SSH или сети на удалённой машине;
- передача ключей, токенов и паролей в ответах, логах, тикетах.

## Без подтверждения (L0)
Чтение: файлы, логи, процессы, статусы, метрики, поиск в интернете, черновики ответов, заметки в памяти агента.
