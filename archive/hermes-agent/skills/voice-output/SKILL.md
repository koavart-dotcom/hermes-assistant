# Голосовой вывод через плазму

Каждый ответ агента в Telegram и CLI озвучивается на Mac хуком `~/.hermes/agent-hooks/speak.py`
(Piper, голос ru_RU-dmitri; звук идёт на текущее устройство вывода macOS — плазма LG по HDMI).
Зачитываются первые ~700 символов без кода, ссылок и разметки. Фоновые задания (cron) не озвучиваются.

## Команды Артема → действие
| Артем говорит | Что сделать (через terminal) |
|---|---|
| «замолчи», «без голоса», «выключи звук» | `touch ~/.hermes/agent-hooks/speak.off` и ответить одной короткой строкой «Голос выключен» |
| «говори», «включи голос», «со звуком» | `rm -f ~/.hermes/agent-hooks/speak.off` и ответить «Голос включён» |
| «проверь звук», «скажи что-нибудь» | ответить короткой фразой: хук озвучит её сам, отдельно ничего запускать не нужно |
| «тише/громче» | `osascript -e "set volume output volume 30"` (0–100), затем подтвердить |

## Правила
- Когда голос включён, писать ответы так, чтобы их было удобно слушать: сначала главное одной-двумя фразами, детали ниже.
- Не вставлять в первые строки ответа длинные команды, пути и таблицы — они попадут в озвучку.
- Устройство вывода не переключать без просьбы Артема.
