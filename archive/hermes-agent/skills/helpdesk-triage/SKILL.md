# Триаж хелпдеска Deka (L0)

Хелпдеск — FreeScout, `https://helpdesk.deka.ua`. Ключ агента в `~/.hermes/.env` (`FREESCOUT_API_KEY`), заголовок
`X-FreeScout-API-Key`. Ящики: 1 IT Support, 2 Developers, 3 Техотдел, 5 Маркетинг.

## Если Артем спрашивает про хелпдеск в чате (не cron)
Один вызов terminal, без импровизаций с curl и парсерами:
```bash
python3 ~/.hermes/scripts/helpdesk_new.py --all
```
Он выводит JSON: `unassigned_total` (все без исполнителя по всем ящикам, без корзины) и `tickets` (без исполнителя за 14 дней +
обновлённые за 5 ч, с полем `mailbox`). Без флагов скрипт показывает **только ящик IT Support (support@deka.ua)**: заявки на Артеме (исполнитель Artem Kovalenko,
id 4) плюс без исполнителя за 14 дней — это режим cron; им же отвечай на вопросы «что на мне», «что не разобрано».
Другие ящики — только если Артем прямо их назвал: `--mailbox 2` (Developers), `--mailbox 3` (Техотдел),
`--mailbox 5` (Маркетинг), `--mailbox all` (все ящики). `--all` — общий режим по всем ящикам без фильтра по исполнителю. Отфильтруй по ящику, о котором спросили («IT Support», «саппорт» = IT Support;
«девы», «разработчики» = Developers; «техотдел»; «маркетинг»), и сразу отвечай в формате ниже. Если спросили про всё
активное или конкретную заявку — один GET:
```bash
curl -sS -H "X-FreeScout-API-Key: $FREESCOUT_API_KEY" "https://helpdesk.deka.ua/api/conversations?mailboxId=1&status=active,pending&pageSize=100"
```
(mailboxId: 1 IT Support, 2 Developers, 3 Техотдел, 5 Маркетинг; `assignedTo=` пустое — без исполнителя.)
Не больше 2–3 вызовов инструментов на вопрос. В ответе всегда называть, за какой период и по какому ящику цифры.

## Источник данных для cron
С 14.10.2026 cron идёт 3 раза в день (9:00, 14:00, 17:00, пн–пт) и смотрит **только ящик IT Support (support@deka.ua)**:
**заявки на Артеме Коваленко + без исполнителя** (активные и ожидающие; без исполнителя — тронутые за 14 дней, остальной
бэклог счётчиком). Другие ящики (Developers, Техотдел, Маркетинг) в cron не входят — только по команде Артема в чате.
Скрипт `~/.hermes/scripts/helpdesk_new.py` уже положил в промпт JSON:
- `sidebar` — счётчики ровно как в боковой панели FreeScout у Артема: Неназначенные, Мои, Черновики, Назначенные, Спам, DBA
  (это активные заявки; корзина исключена). Эти цифры выводить первой строкой сводки как есть, не пересчитывать.
- `tickets` — заявки без исполнителя и на Артеме (`id`, `number`, `status`, `subject`, `customer`, `assignee`, `created`,
  `updated`, `last_customer_message`, `url`, `why` — «без исполнителя»/«на Артеме» + «новая»/«обновлена»/«в работе»;
  `status: pending` = «ожидает», в панели «Неназначенные» такие не считаются, но показать их нужно). Про заявки других исполнителей и других ящиков в cron-сводке не писать.
Если нужно уточнить конкретную заявку — только GET:
```bash
curl -sS -H "X-FreeScout-API-Key: $FREESCOUT_API_KEY" "https://helpdesk.deka.ua/api/conversations/<id>?embed=threads,tags"
```

## Что сделать
1. Для каждой заявки определить категорию: `сеть`, `ПК/оргтехника`, `1С/учёт`, `доступы/учётки`, `принтеры`,
   `почта`, `разработка (BASA/BPM/сайт)`, `маркетинг`, `прочее`.
2. Срочность: `высокая` — не работает у многих / магазин / касса / 1С-сервер / «срочно»; `обычная` — остальное;
   `низкая` — пожелания, вопросы без блокировки.
3. Отметить дубли и похожие темы среди переданных заявок (один и тот же клиент/тема).
4. Предложить, кому передать (очередь: IT Support — сисадмины; Developers — разработчики; Техотдел — техники по
   магазинам/оборудованию), и одну фразу — что бы ты сделал первым шагом.

## Формат ответа (Telegram, по-русски, коротко)
```
🎫 IT Support, <время>: Неназначенные 1 · Мои 0 · Черновики 9 · Назначенные 7 · Спам 2 · DBA 4
— На Артеме: … (или «нет»)
— Без исполнителя (M новых/обновлённых):
🔴 #4183 [IT Support] немає підключення до сервера 1с_кава — Имя Фамилия · 1С/сеть · первый шаг: проверить доступность сервера 1С
🟡 #4186 [IT Support] Создать рабочие имейлы — … · доступы · очередь: сисадмины
⚪ #4187 … 
Дубли: #4182 ≈ #4179 (один клиент, BASA приказ)
```
Не больше 15 строк; если заявок больше — сгруппировать по категориям и показать счётчики. Если изменений нет —
строка со счётчиками панели + «изменений нет»; если `tickets` пуст — строка панели + «заявок на тебе и без исполнителя нет».

## Правила (обязательны)
- **Только чтение.** Никаких POST/PUT/DELETE к API хелпдеска: не назначать, не отвечать клиенту, не менять статус,
  не добавлять заметки и теги. Это уровень L0; любое изменение — только после отдельного явного «ОК» Артема.
- Персональные данные клиентов (телефоны, пароли из текста заявки) в сводку не переносить.
- Не делать выводов о технических причинах без данных: формулировать как «похоже на…», «проверить…».
