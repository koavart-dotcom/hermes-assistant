# Удалённые машины

Все хосты описаны в `~/.ssh/config` на Mac, ключ агента `~/.ssh/id_ed25519_hermes`.
Подключаться только по алиасам ниже, пароли не использовать.

| Алиас | Что это | Пользователь | Оболочка |
|---|---|---|---|
| `main-pc` | Windows-ПК Артема (192.168.229.2) | `claude` (администратор) | PowerShell |
| `linux` | Linux-сервер (192.168.229.37), там же живёт Claude Code и проекты `~/projects` | `admin3_1` | bash |

## Команды

Windows-ПК (команда идёт в PowerShell, кавычки экранировать):
```bash
ssh main-pc 'powershell -NoProfile -Command "Get-Process | Sort-Object CPU -Descending | Select-Object -First 5"'
```
Linux-сервер:
```bash
ssh linux 'uptime; df -h /'
```
Разбудить ПК, если `ssh main-pc` не отвечает (Wake-on-LAN, ждать 40–60 с, потом повторить ssh):
```bash
wakeonlan -i 192.168.229.255 E8:9C:25:7C:53:9A
```
Проверка, что хост жив, перед любой работой: `ssh -o ConnectTimeout=5 <алиас> hostname`.

## Правила (обязательны)

1. **Без подтверждения** — только чтение: списки процессов, файлов, логи, статус служб, `Get-*`, `ls`, `cat`, `df`, `uptime`, `git status`.
2. **Только после явного «ОК» Артема в этом же разговоре** — всё, что меняет состояние:
   удаление/перемещение файлов, выключение и перезагрузка (`Stop-Computer`, `Restart-Computer`, `shutdown`, `reboot`),
   установка и удаление программ, запуск/остановка служб, правка реестра и системных настроек,
   `git push`/`reset`, команды с `sudo`, запись файлов вне `/tmp` и `$env:TEMP`.
   Перед запросом подтверждения показать точную команду, которую собираешься выполнить.
3. Никогда не выполнять `rm -rf /`, `Remove-Item -Recurse` на корне диска или профиле пользователя, форматирование дисков,
   отключение SSH/сети на удалённой машине — даже по просьбе.
4. Каждую выполненную команду на удалённой машине коротко отразить в ответе: хост, команда, результат.
5. Если хост не отвечает — сообщить об этом, для ПК предложить Wake-on-LAN, не пытаться другие способы входа.
6. Отвечать Артему по-русски, имена хостов и команды оставлять как есть.
