# AI Agent — персональный ИИ-агент («как Джарвис»)

Проект создан 11.10.2026. Совершенно новый агент, НЕ связан с проектом Jarvis (локальная LLM в Deka).
Цель: ассистент, который принимает задачи голосом/текстом, выполняет действия и отчитывается.

## Статус
Пустой скелет. Уточнить у Артема: назначение (личный/рабочий), каналы ввода (голос, Telegram, терминал),
какие действия должен уметь, где работает (ПК, сервер), на какой модели.

## Структура
- `docs/` — концепция, архитектура, схемы (Mermaid)
- `private/` — ключи и токены (в git не включать)
