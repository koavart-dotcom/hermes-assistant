# Дизайн-система Hermes Assistant — HUD «Джарвис»

Обновлено: 16.10.2026 (v0.15.0). Источник истины — `src/index.css` (токены как CSS-переменные,
подключены в Tailwind 4 через `@theme inline`), компоненты — shadcn/ui (preset `radix-nova`),
значки — lucide. Экраны: Чат, Подтверждения, Голос (реактор), Состояние, Настройки, окно «Мои
тикеты», плавающий реактор (`#/hud`).

## Принципы
1. **Тёмная палуба по умолчанию.** Реактор живёт на тёмном фоне; тёмная тема — основная,
   светлая («бумага») — с тем же голубым акцентом, переключается в боковой панели.
2. **Один акцент.** Голубой реактора (`--hud`, #4fd1ff) — для активного, фокуса, свечения и
   «живого» состояния. Янтарный — запись/внимание, фиолетовый — «думает». Никаких других
   цветных акцентов в интерфейсе.
3. **Тихая геометрия.** Тонкие линии (hairline), панели с едва заметным свечением, радиус 12 px,
   заглавные подписи с разрядкой для разделов. Без неоновых рамок повсюду: свечение только у
   выбранного и у реактора.
4. **Всё — токены.** Цвета, радиусы, тени, длительности, z-index берутся из `:root`/`.dark`;
   в компонентах нет «сырых» hex-значений.

## Утилиты-мотивы (`@utility`)
- `hud-panel` — карточка: рамка, полупрозрачная поверхность, тень sm. Для разделов настроек,
  ответов ассистента, тикетов, списка состояния.
- `hud-panel-glow` — то же с голубым свечением: только выбранное/активное.
- `hud-label` — подпись раздела: 11 px, заглавные, разрядка 0.18em, приглушённый цвет.
- `hud-hairline` — линия-градиент (прозрачный → голубой → прозрачный) под заголовками.
- `hud-grid` — сетка 32 px с радиальной маской, фон за реактором.

## Типографика
Geist Variable; заголовки страницы 16 px/600 с `tracking-tight`, подписи `hud-label`, основной
текст 14 px, вспомогательный 12 px `text-muted-foreground`, код и идентификаторы — `font-mono` 12 px.

## Отступы и сетка
База 4 px (Tailwind). Страница: шапка 56 px, контент `p-6`, ширина форм `max-w-xl` (36 rem),
чата `max-w-3xl`. Боковая панель 224 px, список диалогов 240 px.

## Состояния голоса (общие для реактора, боковой панели и экрана «Голос»)
| Фаза | Цвет | Движение |
|---|---|---|
| off | серый, свечение 35 % | почти неподвижно |
| idle / listening | голубой | медленное вращение колец |
| recording | янтарный | быстрее, ядро растёт от громкости |
| transcribing / thinking | фиолетовый | бегущий сканер |
| speaking | голубой, полная яркость | кольцо-эквалайзер от громкости озвучки |

## Доступность
Контраст текста в обеих темах ≥ 4.5:1 (основной ≥ 7:1), фокус — `ring` голубой 2 px, все
управляющие элементы с `aria-label`, анимация реактора — `aria-hidden`, уважаем
`prefers-reduced-motion` (планируется: замедлить кольца).
