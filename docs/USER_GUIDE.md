# Hermes Assistant — как пользоваться (v0.20)

Личный помощник «Джарвис» на ПК: голос, чат, быстрые команды без модели, хелпдеск Deka, браузер.
Обновляется сам (баннер «Доступна версия…» → «Обновить»).

## Три режима голоса (экран «Голос»)
- **Чат** — только текст.
- **Голос по кнопке** — удерживайте реактор, пробел на экране «Голос» или горячую клавишу
  (по умолчанию `Ctrl+Shift+Space`, меняется в «Настройки → Голос Джарвиса»), говорите, отпустите.
- **Всегда слушает** — реагирует на фразы, начинающиеся с «Джарвис» или «Гермес». В «Настройках»
  можно разрешить быстрые команды без обращения.

«Тихо» / «я на звонке» — помощник молчит и реагирует только на «слушай» / «звонок закончился».

## Что говорить
Полный список с поиском — экран **«Команды»**. Самое нужное:

| Сказать | Что произойдёт |
|---|---|
| «мои задачи», «что на меня назначено» | окно «Мои тикеты» + озвучка сводки |
| «сводка», «доложи обстановку» | сводка по хелпдеску голосом, в чат и в Telegram |
| «ответь на тикет 4226» → «отправляй» | черновик ответа от вашего имени → отправка клиенту после подтверждения |
| «открой тикет 4226» | заявка в браузере |
| «найди в ютубе …», «включи …», «включи первое видео» | поиск и запуск видео |
| «включи видео», «пауза» | воспроизведение/пауза открытого ролика |
| «загугли …», «открой сайт github.com», «переведи …», «найди на карте …» | поиск и сайты |
| «прочитай страницу» | пересказ открытой вкладки голосом |
| «напечатай …» | текст печатается в активное окно |
| «открой браузер / телеграм / вс код», «запусти программу paint» | программы (повтор — фокус на открытое окно) |
| «сверни все окна», «окно влево», «закрой окно», «новая вкладка», «назад», «обнови» | окна и браузер |
| «громче», «тише», «без звука», «следующий трек» | звук и медиа |
| «скриншот», «заблокируй экран», «выключи компьютер» (с подтверждением) | система |
| «покажи джарвиса» / «скрой джарвиса» | реактор поверх всех окон (удержание = говорить, двойной клик закрывает) |
| «попроси Клода …» | задача Claude Code через мост (проект из настроек) |

Всё остальное уходит модели: вопросы, тексты, действия на ПК через инструменты Hermes.

## Настройки
- **Модель** — локальные модели Ollama (и скачивание новых), Jarvis Deka, облачные провайдеры.
- **Распознавание и озвучка** — размер Whisper и язык; голос Piper/Edge/OpenAI/ElevenLabs/Gemini, «Проверить голос».
- **Голос Джарвиса** — набор реакций (импорт голосов Luxify), громкость, тихий режим, слова-обращения,
  горячая клавиша, «требовать слово-обращение».
- **Сводка хелпдеска** — расписание, озвучка, Telegram, «Сводка сейчас».
- **Интеграции и ключи** — FreeScout, Telegram, облачные ключи; после изменения — «Перезапустить Hermes».

## Если что-то не так
- Белое или пустое окно, нет голоса — сначала «Настройки → Проверить обновления», затем сказать Артему
  (журнал приложения читается удалённо через Control API).
- `F12` в любом окне открывает консоль разработчика.
